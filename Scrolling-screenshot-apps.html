How to install (Windows)

1

Install Python

Download Python 3.8 or newer from python.org. During install, check “Add Python to PATH”.

2

Install dependencies

Open Command Prompt or PowerShell and run:

pip install pyautogui pillow opencv-python
3

Save ScrollShot

Put scrollshot.py in your Downloads or Desktop folder. That’s it.

Tip: On first run Windows may show a SmartScreen warning. Click “More info” → “Run anyway”. It’s a local Python script.

How to use (3 steps)

01

Open what you want to capture

Bring the window to the front. Scroll to the very top of the page.

02

Run ScrollShot

Double-click scrollshot.py, or run in terminal:

python scrollshot.py
03

Select area and watch

Click and drag to select the scrolling region. Press Enter. ScrollShot will auto-scroll and save scrollshot_[timestamp].png to the same folder.

Customize

Add flags to control speed, delay, and output. All optional.

Flag What it does Example
--delay Wait time between scrolls (for slow pages) 0.8
--output Custom filename fullpage.png
--scroll Pixels to scroll each step 600
--no-stitch Save individual frames only — 
python scrollshot.py --delay 0.5 --output notion-export.png

Troubleshooting

Screenshot is cut off or has seams

Increase delay: --delay 1.0. Some sites animate on scroll. Also disable sticky headers in the browser, or reduce scroll step to --scroll 400.

“pyautogui not found” error

Run the pip install command again. If you have multiple Python versions, try py -m pip install pyautogui pillow opencv-python.

Nothing happens after selection

Make sure the target window stays focused. Don’t move the mouse during capture. On macOS, grant Screen Recording permission in System Settings → Privacy.

Image is huge / out of memory

Very long pages create large PNGs. Capture in sections, or add --no-stitch to save frames and stitch later in an image editor.
